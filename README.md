## 🚀 Featured Projects

### 🌍 [Multilingual Document Parser](https://github.com/prakritipatkar/multilingual-document-parser)
AI pipeline for multilingual document understanding — PaddleOCR + YOLOv8 + NLLB-200 + Gemini/Claude. Supports text extraction, figure detection, translation, and semantic Q&A. **80% extraction accuracy across 9 languages.**

### 🏥 [CareConnect](https://github.com/prakritipatkar/CareConnect)
Full-stack doctor appointment booking system with Firebase auth, AI chatbot, Nodemailer email confirmations, and separate patient/doctor dashboards. Built with React 18 + Node.js + Express.

### 📈 [NSE Option Chain Analyzer](https://github.com/prakritipatkar/NSE_Option_Chain_Data)
Real-time NSE option chain data fetcher and OI/IV visualizer for NIFTY & HDFCBANK. Auto-loops every 3 minutes. Built with Python + Jupyter.

### 🧠 [Resume Parser App](https://github.com/prakritipatkar/resume-parser-app) · [Live Demo](https://resume-demo.onrender.com)
Upload a PDF resume → AI extracts structured fields → ask custom questions via Gemini QnA interface. Flask + Gemini API.

### 🏏 [Cricket Auction Price Predictor](https://github.com/prakritipatkar/cricket-auction-predictor)
XGBoost + Scikit-learn model that predicts cricket player auction prices from career stats. **89% accuracy.**

### 📍 [Check-in — Geolocation Attendance](https://github.com/prakritipatkar/check-in)
Geofencing-based attendance app with boundary validation, proxy prevention, and an HR real-time dashboard. React + Node.js + MongoDB.
